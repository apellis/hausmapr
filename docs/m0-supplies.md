# M0 supplies

Everything here is for building a trustworthy reference ("ground truth") for the three test rooms. Prices are rough estimates, not quotes.

| Item | Why | Notes |
| --- | --- | --- |
| Laser distance meter | Reference wall, ceiling and opening measurements | Any basic model rated about ±2 mm (±1/16 in) is enough. A Bluetooth model saves typing but isn't required. Typically under $100. |
| 25 ft tape measure | Short spans, sill heights, checking the laser | You may already have one. |
| Printed calibration board, mounted flat | Gives the photos a known real-world scale (M1) | Print `markers/charuco_letter.pdf` at 100% on letter paper, check one square with the tape, then glue it to foam board or cardboard. About $5. |
| Painter's tape | Marks the points you measured so they're the same each time | Optional. |

Skip renting a scanner for now. If the laser numbers from two passes agree within 5 mm, that's good enough to judge a 5 cm target.
